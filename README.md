# 課題 7-3: クラスの作成

### 課題の説明
魔法使いを表現する`Wizard`クラスを作成しなさい。

また、実行例にあわせて`Prog73`クラスの`main`メソッドを作成しなさい。

ただし、魔法使いの名前は実行時引数（`args[0]`）で与えるものとする。

#### 【Wizard クラスの仕様】
・フィールド:
| フィールド名 | 型    | 初期値 |
|--|----------|--------------|
| `name` | `String` | なし  | 
| `hp` | `int`    | `100`   |  
| `mp` | `int`    | `20`   |  

・メソッド:
| メソッド名 | 戻り値の型    | 引数リスト        | 処理内容                         |
|-------|----------|--------------|------------------------------|
| `fire`  | なし（`void`）       | なし           | 「魔法使い<name>は魔法を唱えた！」と表示し、このインスタンスの `mp` を `5` 減らす |
